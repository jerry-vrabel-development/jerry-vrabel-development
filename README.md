## Projects

**[Quest Log](https://github.com/jerry-vrabel-development/quest-log)** · [try the demo](https://quest-log.forwardslash.workers.dev/?demo)
An ADHD-friendly task app built on behavior design: tiny first steps, variable rewards, nothing ever punished. Strict TypeScript PWA on Cloudflare Workers (D1, KV, R2) with end-to-end encrypted sync, push reminders, and a Claude connector (MCP server behind OAuth 2.1). Vitest and Playwright tests run in CI on desktop, Android and iPhone.

**[Quest Log Insights](https://github.com/jerry-vrabel-development/quest-log-insights)** · [API docs](https://quest-log-insights.forwardslash.workers.dev/docs)
A FastAPI service on Cloudflare's Python Workers that turns a Quest Log export into an accomplishments report. Strict mypy, Ruff, and pytest with a 95% coverage floor.

**[Castmaker](https://github.com/jerry-vrabel-development/castmaker)**
A character generator with one shared character model and modes for game masters and writers. Strict TypeScript and Vite, with unit, snapshot and accessibility tests.

**[Obedience AI](https://github.com/jerry-vrabel-development/obedience-ai)**
Reward-based dog-training plans built with the Claude API, with a safety check enforced on the server.
